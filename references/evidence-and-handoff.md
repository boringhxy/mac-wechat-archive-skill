# 证据与交接

## 结论必须附带范围

“完整”“一致”“可读”都必须指出对象、时间、方法和环境。不同层级的结果不互相替代；未知项写“未知/未验证”，不补造通过。

| 观察 | 可报告 | 不能推出 |
|---|---|---|
| 目录盘点、大小或时间相符 | 指定范围已盘点 | 文件内容相同 |
| 归档整体SHA匹配 | 该归档与记录字节值相符 | 归档已覆盖所有微信数据 |
| 已枚举路径逐文件SHA匹配 | 指定快照路径集合的内容核验通过 | 源本来无缺失、数据库内部正常、账号可登录 |
| 最新清单已应用，活动路径检查通过 | 工作文件视图与该清单相符 | 原生消息、原图、视频均可解释 |
| 微信进程打开测试路径数据库 | 当时实际访问该路径 | 原图和视频已经显示或来自备份 |
| 用户确认指定样本 | 所记录环境/时间下这些样本当时可读 | 全部会话完整、所有附件已验证、备份独立恢复 |
| 路径回退核对通过 | 本次命名空间回到初始状态 | 数据未来永远可恢复 |
| 用户删除后测量容量 | 测量时有多少可用、相对基线增加多少 | du占用必定等于释放量 |

文件内容与元数据也分开。属性差异、未保存的依赖、未读取项及未应用标志均记录；不能保留差异报告后仍说位对位“原样恢复”。

## 原生检查要记录的环境

- 检查时间、macOS和微信版本、机器/系统用户/微信账号上下文，用私有标识即可，不公开账号或凭证。
- 外置卷身份/文件系统/可用空间/读写状态、映像格式与内部空间、可测的连接方式和I/O错误；未测接口、型号或介质健康就写未知，不凭一次校验认证硬盘健康。
- 本次快照和清单身份；实际挂载/替换的范围，哪些配套目录、配置和登录状态仍来自本机。
- 网络状态、可能的在线获取、缓存/媒体来源，以及无法确认的项。没有排除在线或其他本机来源时，不能说样本完全由归档提供。
- 用户原话、具体样本类型、数量和时间范围。用户只说“正常”时保留这个粒度，不补造逐项检查。
- 与测试前相比工作映像是否可能被微信写入。历史哈希仅证明它对应的快照时点；不对写入后的现状自动延长有效性。

同机也不是永久兼容环境。重新登录、升级应用/系统或改变配置后要重新判断。跨机、跨系统用户、跨账号和版本迁移不在此前检查的结论内。不要拷贝系统钥匙串或关闭安全机制弥补未验证的依赖。

## 私有任务记录

运行状态不放在技能或公开仓库。沿用已够用的现有格式，至少能回答：

| 信息 | 内容 |
|---|---|
| scope | 当前只读还是允许复制/切换，允许写入位置，删除由谁执行，手机是否排除 |
| source | 本次真实路径、类型、设备/inode；existing、absent、new-data、symlink或mounted |
| snapshot | 已枚举根、已知排除项、稳定性、清单身份与错误 |
| archive/view | 归档、工作映像、布局、增量仅保存还是指定活动视图已应用 |
| verification | SHA覆盖对象/路径数/逻辑字节、非文件覆盖、元数据差异、证据时间 |
| process | PID、脚本/命令及参数、启动时间、日志、心跳；核对防PID复用 |
| transaction | 本次初始身份、保留路径、挂载身份、反向动作及已完成动作 |
| native_check | 上述环境和依赖、用户样本结果/未知项、工作副本可能变化 |
| rollback/cleanup | 实际回退结果、用户是否实际删除、助手是否删除、当前容量实测 |
| next_step | 下一步和缺少的用户动作，不能重做或越界的动作 |

动态状态原子更新，历史事件另存日志。事实与报告冲突时先定位原因，不仅修改JSON来凑齐前提。完成后把最终数量与心跳中残留的中途数字对齐。

## 阶段和接续

| 当前事实 | 下一步 |
|---|---|
| 进程活跃且命令匹配 | 监控，不重复复制、应用或启动 |
| 旧PID已被其他程序复用 | 不发信号；读产物和对应报告判断真实阶段 |
| 只有元信息或部分SHA结果 | 继续所需检查，不称内容已核验 |
| 增量已保存但活动视图旧 | 明确尚未应用；按本次需要决定是否应用 |
| 文件视图核验通过，原生检查未做 | 只报告文件结果；如已授权，再做临时原生检查 |
| 用户样本通过但仍临时挂载 | 结果加环境限制，请用户退出后回退 |
| 用户删除报错/放回 | 本地可能已部分删除，不能用剩余目录覆盖可信归档 |
| 用户原件已删除 | 原路径不存在是预期，不要求历史inode仍存在 |
| 新目录后来产生 | 捕获新身份并保护新消息，不套旧保留路径或直接合库 |
| 电脑范围结束、手机排除 | 明确收尾，不自动扩展后续工作 |

内容失败、身份不符、源不明变化、未知活动文件或回退失败时，保留产物并停相关写入。只向核实为本任务的进程发必要信号；接续不能以丢弃既有进度重新全做代替。

## 交接内容规格

写本次事实，不抄历史值：当前目标与边界；动态记录和日志位置；快照、实际进程与挂载；各层证据/未知项；原路径初始状态与保留位置；下一步用户动作；回退方式；禁止重复的操作。

优先停在文件检查完成、原路径未切换的点。已切换时明确外盘依赖及如何退出/回退，不能写成已经暂停、卸载或结束。对外结论应先说具体完成了什么，再说明仍有什么未验证。
