# 环境检测与流程选择

本技能按当前能力与证据选择流程，不提供微信数据库转换器或通用版本白名单。文件可保存、映像可挂载、微信样本可读、回退完成是不同结果。仅修改技能说明不会让未经测试的系统自动获得兼容性。

## 先记录当前组合

只读获取本次允许范围内的信息；每个值附测量时间及来源，查不到则写未知。不得为了探测而自动启动、升级或降级微信。源快照与目标环境分别记录：

| 层次 | 需要的事实 |
|---|---|
| 系统与应用 | macOS 版本/构建、架构、微信版本/构建与应用标识；源快照当时的值及当前读取端的值，不用当前版本补写历史 |
| 数据布局与依赖 | 实际源根、数据库/附件及活动日志的位置、源到工作视图映射、系统用户/微信账号上下文、仍用本机的配套目录及网络/缓存未知项；不读取无关正文或凭证 |
| 存储 | 宿主卷身份与文件系统/读写状态，映像格式与内部文件系统、外盘/映像内部/内盘容量和峰值；不按盘名或逻辑容量猜测 |
| 当前证据 | 探针、清单与核验所对应的快照、用户原生样本、回退、当前授权和阻断点；各项独立记录 |

即使版本号相同，也要核对当前布局、挂载与空间。跨系统用户、跨机器、跨账号、系统或微信升级、映像格式/内部文件系统改变时，相关证据需重新判断；不要求无理由重做未受影响的全量文件核验。

## 三种状态及动作

状态描述证据，不授予权限。历史记录与当前可执行条件分别保存；当前故障可以阻断有历史样本的组合。每条记录注明缺失字段，不能用“已有样本”掩盖组合信息不全。

| 状态 | 含义 | 当前可推进范围 |
|---|---|---|
| 已有样本记录 | 某次环境和限定样本有用户可读确认；记录各字段来源与未知项 | 当前前提仍须实查，不能据此跳过授权、探针、文件/布局检查或清理复核；可复用仍有效证据 |
| 待验证 | 缺当前能力、布局或原生读取证据；尚无已知条件失败 | 默认只读盘点；文件归档仅按已授权范围执行，不自动切换原路径。已明确授权本次受控检查时，可按下节逐步取得证据，不要求先有历史成功样本 |
| 条件不满足 | 本次出现挂载/读写失败、空间不足、未知活动文件、身份冲突或回退失败等阻断点 | 停止受影响写入与切换，保留现状和产物；可在授权内继续不受影响的只读检查。已切换时按实际事务状态处理，不盲目重试 |

“待验证”不是永久不支持；“条件不满足”也不必然是版本不兼容。只报具体失败。状态不能替代原生与回退字段：样本已可读但尚未回退时，仍不具备清理条件。

## exFAT 与目标系统能力探针

可采用的候选结构为 **exFAT 宿主卷 → 普通读写 DMG → 内部 APFS → 微信工作数据**。外盘不因此格式化；同为 exFAT 不能证明不同映像格式、系统或微信均兼容。按[硬盘条件](storage-conditions.md)计算三层空间。

APFS 的文件系统支持从 macOS 10.13 开始；这不是微信最低系统要求，也不是任意 APFS 特性或映像均能跨系统读取的保证。Apple 将映像描述为可包含文件和文件夹、并可选择内部格式的文件。[文件系统说明](https://support.apple.com/en-me/guide/disk-utility/dsku19ed921c/mac)、[创建映像说明](https://support.apple.com/zh-cn/guide/disk-utility/dskutl11888/mac)。

只有本次授权允许在指定外盘任务目录创建和挂载测试文件时，才可做能力探针。只读请求不包含探针授权；用户禁止检查时说明条件不足并停止，不擅自检查。

1. 在独立、唯一的新路径使用目标系统支持的较小映像，容量按工具限制和实际余量决定；只写中性的测试文件，不装载聊天数据、不接触微信原路径、不覆盖已有产物。
2. 对计划使用的同种映像格式/内部文件系统验证创建、附加、写入读回、所需链接/属性和正常卸载，记录具体项目、错误和未测能力。已有同环境且仍有效的探针可复用，不因每次调用机械重建。
3. 失败则停止相关写入与正式切换；不自动格式化物理盘、换成未验证格式、反复重试或新建整套数据副本。保留探针与证据，遵守用户不清理的约定。

目标系统无法使用所需映像/APFS 时，不套用此原生读取分支；可在存储条件允许且已授权时保留文件归档，不假称原会话可读。不为老系统自动建立 HFS+ 等新格式分支。将来确需其他格式时，另按同样能力检查形成记录。

## 微信版本与受控原生检查

不靠改目录名、替换数据库或合并两条时间线实现跨版本。先查清源布局与当前客户端所需映射；无法建立有依据的映射或存在未知活动项时，不进入原路径切换。文件归档可以按已授权范围继续，但不是通用导入。

当前组合虽无成功记录，只要本次授权已覆盖受控原生尝试，存储能力、布局与指定文件视图检查通过，源已稳定、微信退出且回退身份/容量准备成立，就可按[操作细节](workflow.md)尝试。缺少授权或前提时说明具体缺口；已有明确授权不重复确认，不要求先有成功记录造成循环阻断。

始终保留输入归档、当前原件和工作副本中的新变化，优先复用既有产物及差异保留。新版本打开工作数据可能产生的改写按变化管理；原内容核验不自动覆盖改写后状态，不保证改写后的数据还能交给旧版，不自动降级应用、转换数据库、取用钥匙串或放宽安全策略。

由用户登录并实际查看限定文字、原图和视频，记录版本、日期、样本范围、依赖和未知项；用户退出后核对本次回退。仅更新对应快照和组合的样本记录。未来或跨机读取不在结论内。

## 清理与接续

兼容状态、完整字段、探针通过和静态安全扫描都不是删除许可。为保留原会话读取能力而释放空间时，未知组合尚未取得所需原生样本证据，或当前能力/布局检查有阻断，不给删除指引。单纯归档任务在文件结果处结束，不自动进入清理。

给清理步骤前，仍须完成[清理前当次复核](workflow.md#7-用户手动清理与推出)，并核对相关原生证据适用范围；回退失败或所需回退未完成时不进入清理。从未切换则按操作细节记录回退“不适用”。即使全部条件成立，也只由用户本人执行，且不承诺未来全部原会话可恢复。

私有交接记录至少保存当前组合及每字段来源/时间、历史样本与匹配差异、三种状态之一及理由、存储探针/布局/内容/原生/回退的独立结果、下一步及所需授权。接续时核实现状，不从旧状态直接升级为支持；公开时仅保留明确允许披露的环境摘要，不附账号、设备唯一标识或任务路径。
